# Cómo contribuir

1. Crear una rama para el cambio.
2. Mantener datos, presentación y comportamiento en sus carpetas correspondientes.
3. No publicar secretos, datos de visitantes ni destinatarios de correo.
4. Conservar CRLF y ejecutar `npm test` y `npm run build`.
5. Probar los cambios visibles en escritorio y celular, también con movimiento reducido.
6. Actualizar documentación y `CHANGELOG.md` cuando cambie el comportamiento.

Evitar dependencias para efectos que puedan resolverse de forma clara con CSS o APIs del navegador.
